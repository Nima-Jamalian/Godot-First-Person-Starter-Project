
# Godot First Person Starter Project

A 3D first-person starter project made with Godot. It provides a foundation for developing first-person games and experimenting with common gameplay mechanics.

## Features

- **Character Movement:** First-person player movement, including walking and jumping.
- **Camera Rotation:** First-person camera controls using mouse input.
- **Raycasting:** Raycast-based detection of objects in front of the player.
- **Collision Detection:** Detection and handling of collisions between the player and other physics bodies.

## Requirements

- [Godot Engine 4.7.2 (Stable)](https://godotengine.org/)

## Getting Started

### 1. Download the Project

Download the project as a ZIP file from GitHub and extract it.

### 2. Open the Project in Godot

1. Open Godot Engine 4.7.2.
2. Select **Import** in the Project Manager.
3. Navigate to the downloaded or cloned project folder.
4. Select the `project.godot` file.
5. Click **Import & Edit** to open the project.

### 3. Run the Project

Once the project is open:

1. Press **F6** to run the currently open scene.
2. Alternatively, press **F5** to run the main project scene.

Use the mouse to look around and the keyboard to control the player.

## Project Structure

The project is organised into folders for scenes, scripts and other resources.
